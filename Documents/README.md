# Ghostlight Isles: project documents

Everything about the idea, the plan and the hackathon lives in this folder. The code lives in `src/`, and Kiro's steering, specs and hooks live in `.kiro/`.

| File | What it holds |
|---|---|
| [idea-brief.md](idea-brief.md) | The original pitch, story, core loop, category and prizes we aim for (some details changed while building; `game-design.md` describes the game as built) |
| [game-design.md](game-design.md) | Every game system with its numbers, as built |
| [build-plan.md](build-plan.md) | The schedule, checkpoints, what to cut if we fall behind, and what's done |
| [submission-checklist.md](submission-checklist.md) | Devpost requirements, judging criteria, prizes and deadlines |
| [kiro-usage-log.md](kiro-usage-log.md) | Running notes for the "How I used Kiro" write-up |
| [credits.md](credits.md) | Every third-party asset, its author and its license |
| `screenshots/` | Screenshots taken by the smoke test, for the README and Devpost |

## Third-party assets
Every model, texture, sound and font file under `public/` that we did not make ourselves must have a row here before it is committed. `npm run check:assets` fails if a file under `public/models/`, `public/audio/`, `public/textures/` or `public/fonts/` is missing from this table, or if its license is not CC0, CC-BY, OFL or MIT.
